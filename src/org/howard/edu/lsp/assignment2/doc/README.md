# README of ETLPipeline

In this assignment, I created a program that processes the file employees.csv and 
writes the changes from my program to the file transformed_employees.csv.

My program normalizes strings, validates the values (hoursWorked, & hourlyPay), calculates gross pay,
bonuses, paylevel, and employment status of the employees.

This updated information is then stored in transformed_employees underneath the data folder for further use.
